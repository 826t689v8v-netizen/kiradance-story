Privacy Policy - KIRA DANCE Uploader

Last updated: 2026-11-23

KIRA DANCE Uploader ("the tool") is an internal tool used by KIRA DANCE to upload videos to its own YouTube channel. The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

What we access

  • With the scopes youtube.upload and youtube.readonly, the tool uploads videos and thumbnails to the KIRA DANCE channel and reads the list of that channel's own uploads.
  • It does not access, collect or store data about any other person or channel.

Storage and sharing

  • The OAuth refresh token is stored only on the academy's own computer. It is never sent to third parties.
  • No personal data is sold, shared or used for advertising.

Deletion and revocation

  • Access can be revoked at any time at Google security settings. Deleting the local token file removes all stored authorization data immediately.
