KIRA DANCE Uploader

An internal tool used by KIRA DANCE, a dance academy in Anyang, South Korea, to upload its own class videos to its own YouTube channel. It uses YouTube API Services. It is not offered to other users.

키라댄스(KIRA DANCE)가 자체 유튜브 채널에 수업 영상을 올리기 위해 쓰는 내부용 도구입니다. YouTube API 서비스를 사용합니다.
